EggLive 1.6.1 鸡蛋直播 — Windows 10/11 64 位

安装后，双击桌面“EggLive 鸡蛋直播”。USB 摄像头插入后自动查找，也可以在右侧选择设备并点击“连接摄像头”。软件及面捕模型已内置，无需 Node、Python、开发环境或账号。

1. 连接 USB 摄像头，看向镜头，点击“正脸校准”。
2. 点击“打开已配置的 OBS”，自动配置 EggLive 透明形象场景。
3. 带声音录屏时，在 OBS 添加“音频输入捕获”，选择你的麦克风。
4. 在其他视频软件使用时，首次点击“安装虚拟摄像头”并批准 Windows 系统授权，然后点击“启动虚拟摄像头”，其他软件选择 OBS Virtual Camera。

新电脑首次运行时会创建该电脑自己的 OBS 配置。真实摄像头只在 EggLive 中选择，OBS 接收鸡蛋画面；请让 EggLive 保持运行。

无摄像头或没有识别到人脸时，仅显示蛋壳。暂停追踪会释放摄像头。摄像头被其他程序占用时，先关闭占用它的软件。

安装包已附带 Microsoft 官方 C++ x64 运行库；系统缺少或较旧时，安装过程中会尝试安装，并可能要求 Windows 系统授权。取消授权后可在 prerequisites 文件夹重新运行 vc_redist.x64.exe。

本程序仅适用于 Windows x64。未在你的另一台实体电脑上测试过摄像头或显卡。若无画面，可通过“打开诊断日志”查看错误。

卸载可在 Windows 设置 → 应用 → 已安装的应用中找到 EggLive。个人录像与用户设置不会随程序卸载而删除。

直播性能与眼镜反光

默认以 30 帧渲染和输出；默认“省 CPU”画面为 640×360，OBS 自动放大到 1280×720；可在右侧改为均衡 960×540 或清晰 1280×720。人脸定位与对应摄像头画面约 15 帧，眼嘴在相邻配对帧之间平滑过渡，头部动作通过弹性插值保持平滑，面捕在独立后台线程执行。关闭不使用的表情系数计算；贴图柔边和反光抑制由 GPU 执行。OBS 使用本机 WebRTC 视频传输，没有接收端时停止视频编码。

右侧“眼镜反光抑制”默认 85%，可调至 100% 加强或降至 0% 关闭。它抑制白色、青色及蓝紫色反光，不会还原被镜片完全遮住的眼睛。过暗或正常眼白受影响时降低强度。摄像头稍微高于显示器、避免灯正对镜片，也能减少源画面反光。

运行时需要让 EggLive 保持打开；窗口最小化仍可供 OBS 使用。CPU 会随电脑、摄像头格式、显卡驱动和 OBS 的录播编码设置改变。

1.5 稳定性修复：眼嘴贴图与关键点使用同一张摄像头图像，避免异步面捕错位；限制异常头部跳变，短暂漏检保留上一张配对画面，长时间丢脸后渐隐眼嘴；每帧清理深度缓冲，避免连续绘制时出现透明缺口。显示/OBS 输出保持 30 帧上限。


1.6 无镜参考眼睛（针对强眼镜反光）

若调高反光抑制仍有亮斑，请使用右侧“无镜参考眼睛”：
1. 暂时摘下眼镜，正对镜头，点击“① 摘镜记录睁眼”，睁开双眼保持到提示已记录（倒数 3 秒）。
2. 点击“② 摘镜记录闭眼”，完全闭上双眼保持到提示参考已启用（倒数 3 秒）。若未闭眼或没检测到脸会拒绝采集，请重试。
3. 戴回眼镜直播。软件用你的无镜睁眼/闭眼画面，由实时眼睑关键点驱动眨眼；头部与嘴巴继续实时捕捉，镜片图像不进入眼部输出。参考保存后，下次双击启动自动读取。
4. 取消“启用参考眼睛”可以对比实时画面；“删除参考眼睛”移除本机保存的参考。

参考只保存局部双眼图集和开合校准数值，完全离线，不上传；每台电脑需要各自采集，不会随安装包带走上一台电脑的眼睛。采集时必须摘镜，否则会把反光记录下来。

这是参考驱动的眼部替代显示，不是 AI 恢复被镜片挡住的实时眼球：细微眼周表情和眼球视线不会完全跟随，严重反光导致面捕关键点失准时眨眼可能不准。若不接受这种取舍，请取消参考模式；仅调节反光抑制无法可靠还原过曝眼睛。

增量工作在 GPU 上，仅采样两张小参考图并混合，没有额外 AI 网络、没有 CPU 全帧去反光；保持 30 帧输出和原有低占用架构。
